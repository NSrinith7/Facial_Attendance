**Facial Recognition Attendance System**

An Android application developed as part of my Master's in Computing Science at Griffith College Dublin. This project explores the use of facial recognition technology to support attendance management through a mobile application.

## About the Project

The **Facial Recognition Attendance System** aims to simplify attendance tracking by using facial recognition technology. The project uses Google ML Kit as part of its machine-learning functionality and demonstrates the application of computer vision concepts in Android development.

The goal is to explore a more convenient and technology-driven approach to attendance management.

## Key Features

- **Face Recognition:** Uses facial recognition-related functionality in an Android application.
- **Automated Attendance:** Designed to support attendance recording through facial recognition.
- **Android Application:** Built as a mobile application for the Android platform.
- **Machine Learning Integration:** Uses Google ML Kit for relevant machine-learning functionality.
- **Digital Attendance Management:** Demonstrates an alternative to traditional manual attendance-taking methods.

## Technologies Used

- **Programming:** Java/Kotlin, as applicable to the implementation
- **Platform:** Android
- **Machine Learning:** Google ML Kit
- **Development Environment:** Android Studio
- **Model Assets:** TensorFlow Lite (`.tflite`) models

## Getting Started

### Prerequisites

Before running the application, ensure you have:

- Android Studio installed
- A compatible JDK and Android SDK
- Git installed
- An Android device or emulator
- An internet connection for downloading project dependencies, if required

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/NSrinith7/Facial_Attendance.git
   ```

2. Open Android Studio.

3. Select **Open** and choose the cloned `Facial_Attendance` project folder.

4. Allow Android Studio to sync Gradle and download any required dependencies.

5. Connect a compatible Android device or start an emulator.

6. Build and run the application from Android Studio.

Follow any additional setup instructions required by the project.
